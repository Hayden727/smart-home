# STM32 Smart Home System

A course design project for a Bluetooth/WiFi-based smart home control system using STM32F407 microcontroller.

## Project Features:
- 🏠 Complete smart home system with 3D-printed miniature house model
- 📱 Mobile app control via Bluetooth/WiFi (HC05/ESP8266 modules)
- 💡 Multi-device control (lights, curtains, doorbell, etc.)
- ⏰ Additional features including digital clock, timer, alarm, and temperature/humidity monitoring
- 🛠️ Includes hardware design (schematics & PCB), mechanical structure, and firmware

## Key Components:
- STM32F407 MCU
- HC05 Bluetooth module (3.3V powered)
- ESP8266 WiFi module (optional)
- PWM-controlled servos for curtain/door
- OLED display for user interface
- DHT11 temperature/humidity sensor

## Documentation Includes:
- System block diagram
- Detailed hardware schematics
- 3D PCB design
- Complete firmware source code
- Bluetooth/WiFi configuration guide
- Project limitations and improvement suggestions

Perfect for students looking for STM32 course design references or IoT enthusiasts building smart home prototypes.
